## 📌 Proyectos destacados

### 🏠 [Modelo Predictivo de Precios Inmobiliarios — Región de Valparaíso](https://github.com/Sebastian2nunez/Prediccion-Precios-Inmobiliarios-de-la-Region-Valparaiso) · *Ene 2026*
Sistema de ML end-to-end para estimar precios de propiedades con datos reales.

- **Web scraping automático de 995 inmuebles**, EDA exhaustivo y **más de 15 variables derivadas** del dominio
- Comparación de **6 algoritmos** (Regresión Lineal, Ridge, Lasso, Random Forest, XGBoost, Gradient Boosting) con
  cross-validation 5-fold y RandomizedSearchCV
- **R² = 0.67 con Gradient Boosting**, controlando overfitting con regularización y early stopping
- Split estratificado por rango de precio y **análisis SHAP** para identificar los principales drivers del precio

`Python` `scikit-learn` `XGBoost` `SHAP` `BeautifulSoup` `Selenium`

### 🔬 [Calibración de Sensores UV — Seminario de Investigación PUCV](https://github.com/Sebastian2nunez/Photodiode-Sensor-Calibration-via-Non-Linear-Regression) · *Jul–Dic 2025*
Investigación aplicada a astrobiología que combina física experimental y análisis de datos.

- Sistema de **adquisición automática de datos** con integración Arduino–Python
- Modelo de calibración **voltaje → irradiancia** derivado de una ecuación física teórica
- Caracterización de la transmitancia de materiales ópticos (PDMS, vidrio) en distintas longitudes de onda UV

`Python` `Arduino` `NumPy` `SciPy` `Análisis estadístico`
