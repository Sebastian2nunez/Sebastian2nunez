## 📌 Proyectos destacados

### 🏠 [Predicción de Precios Inmobiliarios — Región de Valparaíso](https://github.com/Sebastian2nunez/Prediccion-Precios-Inmobiliarios-de-la-Region-Valparaiso)
Sistema de ML end-to-end para estimar precios de propiedades a partir de datos reales obtenidos por web scraping.

- **Pipeline completo:** scraping → limpieza → feature engineering → modelado
- Modelo de **Gradient Boosting con R² ≈ 0.67** sobre datos reales con ruido
- Análisis crítico de las limitaciones del modelo y de los datos

`Python` `Web Scraping` `scikit-learn` `Gradient Boosting`

- Regresión no lineal aplicada a datos experimentales
- **Interpretación física** de los parámetros ajustados
- Enfoque científico y reproducible

`Python` `SciPy` `Regresión no lineal` `Datos experimentales`
